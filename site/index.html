The board's behaviour.
Your board's look.

list-picker owns the containers, the moves and the order of a kanban board: dragging by pointer or keyboard, screen reader announcements, a linked-list model. You render every card and list header, and it ships no styles.

Install The full demo

Same board, your look:

Drag a card or a list title. Or focus a card, press Space, move it with the arrows and press Space again. Doing holds 3 cards.

Packages

PackageWhat it is
@list-picker/coreThe Board model: ordered lists of ordered cards, events, snapshots. No DOM.
@list-picker/vanillaDraws a Board from your Renderers; pointer and keyboard moves, rules, activation, announcements.
@list-picker/reactThe same board as React components. Page coming soon.
@list-picker/angularThe same board as Angular components. Page coming soon.
